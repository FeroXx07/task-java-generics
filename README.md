# task-java-generics

**Descripció**:
- Crear mètodes genèrics que accepten arguments de qualsevol tipus.
- Combinar objectes genèrics amb tipus específics, incloent-hi la limitació amb interfícies o classes.
- Utilitzar varargs genèrics i descobrir les seves implicacions.
- Aplicar restriccions (`bounded types`) per controlar quin tipus d’objectes es poden passar a un mètode genèric.
- Reforçar la relació entre genèrics, interfícies i polimorfisme.

## 🛠 Tecnologies
- Backend: Java
